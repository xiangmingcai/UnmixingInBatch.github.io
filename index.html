Unmixing In Batch (UIB)

(version 1.0)

This website is designed to help users process unmixing in batch for flow cytometry analysis.

You may simple select the data folder (for raw fcs file), the save folder, and your unmixing matrix csv file, which follows the same format as in the UMO

Be careful, big fcs file (>100 Mb) may crush the website.

If you find this tool helpful, please remember to cite us in your work. View this project on GitHub

Enjoy! 😉
